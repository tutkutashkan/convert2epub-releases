# Convert2EPUB desktop

Official installers for [Convert2EPUB](https://convert2epub.com/) on Mac, Windows and Linux.

Download the newest installer for your computer from [Releases](https://github.com/tutkutashkan/convert2epub-releases/releases). Each release names the platforms it is for. Conversion tools, including OCR, are included in the app; installation does not download them separately.

## Mac

Signed and Apple notarized `.dmg` for Apple Silicon Macs running macOS 26.4 or newer. Open the DMG and drag Convert2EPUB to Applications.

## Windows

`.exe` installer for 64-bit Windows 10 or 11. It installs for the current user, so it needs no administrator prompt. The installer is not code-signed, so Windows may show "Windows protected your PC". Choose **More info**, then **Run anyway**.

## Linux

AppImage and `.deb` for 64-bit Linux. The AppImage needs no installation: make it executable with `chmod +x`, then run it. On Debian or Ubuntu you can instead install the `.deb` with `sudo apt install ./<file>.deb`. Both need Ubuntu 22.04, or a distribution of the same age or newer.

## License

The app requires a one time license for conversions. Open the app and use **Buy license** to reach the [website pricing section](https://convert2epub.com/#pricing). If you already bought a license, use **Restore a license** in the app. Each release lists a SHA-256 checksum for every file so you can verify the downloaded installer.
