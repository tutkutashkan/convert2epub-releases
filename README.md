# Convert2EPUB for Mac

Official signed and Apple notarized installers for [Convert2EPUB](https://convert2epub.com/).

Download the latest `.dmg` from [Releases](https://github.com/tutkutashkan/convert2epub-releases/releases), open it, and drag Convert2EPUB to Applications. The current build supports Apple Silicon Macs running macOS 26.4 or newer. Conversion tools are included in the app; installation does not download them separately.

The app requires a one time license for conversions. Open the app and use **Buy license** to reach the [website pricing section](https://convert2epub.com/#pricing). If you already bought a license, use **Restore a license** in the app. Each release lists a SHA-256 checksum so you can verify the downloaded installer.

For help, contact [support@convert2epub.com](mailto:support@convert2epub.com).
